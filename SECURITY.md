# Безопасность

## Поддерживаемые версии

Обновления безопасности выходят только для последней версии.
Ставь свежую — старые версии не поддерживаются.

| Версия | Поддержка |
|---|---|
| 1.2.1 (последняя) | ✅ |
| 1.2.0 и старее | ❌ |

## Как сообщить об уязвимости

Пожалуйста, **не открывай публичный Issue** — так о проблеме узнают
и те, кто ей воспользуется.

Правильный путь: вкладка **Security** этого репозитория →
**Report a vulnerability**. Сообщение придёт лично мне, до публикации
его никто не увидит.

Что помогает разобраться быстрее:

- версия Speecher (видна в окне «О программе») и версия Windows;
- что происходит и чем это опасно;
- шаги, чтобы повторить;
- если есть — логи из `%LOCALAPPDATA%\Speecher\logs`.
  **Перед отправкой загляни в них**: в логи попадают пути к файлам
  на твоём компьютере.

Отвечаю в течение 7 дней. Если проблема подтвердится — чиню и выпускаю
новую версию, а в описании релиза говорю спасибо тому, кто нашёл
(или не говорю, если ты не хочешь — скажи об этом в сообщении).

## Что входит в зону ответственности

- программа Speecher и её установщик `SpeecherSetup-X.Y.Z.exe`;
- обращение с ключами API и данными пользователя;
- механизм проверки и установки обновлений.

Не входит: уязвимости самих сторонних сервисов (Groq, Hugging Face),
проблемы Windows и чужие сборки программы.

## Как программа обращается с секретами

Ключи API хранятся в `%LOCALAPPDATA%\Speecher\secrets.bin`,
зашифрованные средствами Windows (DPAPI, user scope, с дополнительной
энтропией). Расшифровать файл может только тот же пользователь Windows
на той же машине — скопированный на другой компьютер он бесполезен.
В открытом виде ключи на диск не пишутся и в логи не попадают.

Подробнее о том, какие данные и куда уходят, — раздел «Приватность»
в [README](https://github.com/itsphererepair1-design/speecher-releases#приватность).

## Проверка скачанного файла

К каждому релизу приложен `SHA256SUMS.txt`. Сверить установщик перед
запуском — в PowerShell, в папке со скачанным файлом:

```powershell
Get-FileHash .\SpeecherSetup-1.2.1.exe -Algorithm SHA256
```

Полученная строка должна совпасть с той, что в `SHA256SUMS.txt`.
Не совпала — файл повреждён или подменён, запускать не надо.

## О предупреждении Windows

Установщик пока не подписан платным сертификатом, поэтому Windows
SmartScreen показывает синее окно «Windows защитила ваш компьютер».
Это не признак вируса и не признак его отсутствия — это значит ровно
то, что у файла нет платной подписи. Именно поэтому качать стоит
только со [страницы релизов этого репозитория](https://github.com/itsphererepair1-design/speecher-releases/releases/latest)
и сверять хеш.
